    Set up a scene¶

    A scene that casts skills needs three things: a configuration, a manager and entities (casters and targets). This page builds a test scene step by step: a player and an enemy face to face.

    1. Check the configuration¶

    The configuration (UnleashSkillConfiguration) holds all the game data: stats, teams, entity types, statuses… Nodes pick their values from lists read from it.

    • On the first opening, the editor created a default configuration in Assets/UnleashSkillData/UnleashSkillConfiguration.asset (see Installation): UnleashSkill → Main Menu loads it automatically.
    • Load configuration chooses another one, Create configuration starts from an empty configuration. Or: right-click in the Project window → Create → UnleashSkill → Configuration.

    The loaded configuration is the active configuration of the editor: every dropdown of the nodes and inspectors reads it. It is kept after a recompilation or a restart of Unity (the last one loaded, otherwise the project's). Each section is detailed in Configuration.

    2. Add the manager¶

    1. Create a new scene (File → New Scene, Basic template), and save it.
    2. Create an empty GameObject (GameObject → Create Empty), name it UnleashSkill.
    3. Add the UnleashSkillManager component to it.

    It is the central point of the tool at runtime: it owns the simulation world, the running skill executions, the visual pool and the presentation system. When the component is added, its fields are filled with the project's data:

    Field Role
    Default Configuration Configuration loaded when the game starts. Required: without it, nodes that read a stat or a type find nothing.
    Presentation Library Library of effects, sounds, shakes, module visuals and animations. Empty: the one of the data folder (Presentation/PresentationLibrary.asset), read by the editor and given to the manager by the build.
    Trajectory Library Library of the trajectories read by the Trajectory node. Same rule: empty, the one of the data folder (TrajectoryLibrary.asset).
    Original Prefab Optional. Base object of the skill visuals, copied for each module body. Empty: a built-in empty object.

    One manager per scene.

    Nothing has to be filled by hand for a build: each built scene gives its manager the project libraries it lacks (the project's scene is not modified). If the project has none of them, the build writes it in the console, and the manager says it again when the game starts. A manager created from code at runtime is not completed: place it in the scene, or set PresentationLibrary.Active and TrajectoryLibrary.Active after creating it.

    3. Create the entities¶

    Every entity that casts skills or receives them (player, monster, dummy, summon) has the SkillCaster component.

    1. The player: GameObject → 3D Object → Capsule, named Player, at position (0, 1, 0). Add the SkillCaster component. When it is added, it receives the first team, the first entity type and the first stat template of the active configuration; with the default configuration:
      • Entity Type: Character;
      • Team: Player;
      • Stat Template: Default.
    2. The enemy: another capsule named Enemy, at position (0, 1, 8), that is 8 meters in front of the player (its blue axis, forward). Add a SkillCaster and change its team to Enemy (type Character, template Default).

    An empty field

    The inspector warns about an empty Team, Entity Type or Stat Template. Two entities without a team are allies: a skill filtered on enemies (On hit on Enemy) never touches them. A SkillCaster added from code receives nothing: set its fields yourself.

    The inspector of a SkillCaster offers:

    Setting Role
    Entity Type Type of the entity (Player, Monster…), read by the “Entity type” filters.
    Team Team. Two entities of the same team are allies; a skill has its caster's team.
    Stat Template Starting stat template (HP, mana…).
    Is Targetable Unchecked: the entity is never chosen as a target.
    Lock Controller During Forced Movement Blocks your character controller during a movement imposed by a skill (see below).
    UI sliders Interface bars to update for the stats that have one.

    When its health (HP) reaches zero, a SkillCaster dies: it cancels its skills and its GameObject is disabled.

    Hit shapes (hurtbox)¶

    Skills hit entities through their hurtboxes, simple shapes (sphere, capsule, box) registered in the simulation world. Without settings, an entity gets a capsule derived from its collider or renderer: the capsules of this scene need nothing more. To set it, add the Hurtbox component (menu UnleashSkill/Hurtbox): one or more shapes, and an optional tag (head, weak point) passed along with the impacts.

    Unity colliders are not used by skills

    Skills read neither Physics nor the entities' colliders: everything goes through the simulation world. A collider stays useful to your character controller and to the static scenery.

    Movements imposed by a skill¶

    A knockback, a rush or a pull moves the entity through the component it has: CharacterController first, otherwise Rigidbody, otherwise the transform directly. During an imposed movement, the player's control is locked (Lock Controller During Forced Movement option of the SkillCaster).

    Skill slots¶

    To cast skills by keys (slot 1, 2, 3…), the caster has a SkillSlots component that holds its skills. See Slots, passives and combos.

    4. Test without code¶

    Add the SkillTester component on Player (it adds SkillSlots with it). In Play Mode, it casts slot 0 with Space and slots 0 to 8 with keys 1 to 9: enough to try your skills before connecting them to your own controls (Cast a skill from code). The Link to scene button of the graph editor puts the open skill in slot 0 of the scene's SkillTester. Without a SkillTester in the scene, it offers to create one: a Skill Tester object at the origin, with a SkillCaster (team, type and template of the active configuration) and the SkillTester, plus a Skill Controller object with the UnleashSkillManager if the scene has none. Place it and check its team before playing.
