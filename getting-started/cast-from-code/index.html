    Cast a skill from code¶

    The SkillTester is for trying things out. In a real game, your controls (player) or your AI (monsters) cast the skills, through the SkillCaster API.

    Cast a skill¶

    using UnityEngine;
using UnleashSkill;
using UnleashSkill.Execution;

public class PlayerSkills : MonoBehaviour
{
    [SerializeField] private SkillCaster caster;
    [SerializeField] private SkillGraphModel fireball;

    void Update()
    {
        if (Input.GetKeyDown(KeyCode.Q))
        {
            SkillCastResult result = caster.Cast(fireball, out SkillExecution execution);
            if (result != SkillCastResult.Success)
                Debug.Log($"Cast refused: {result}");   // on cooldown, not enough mana, stunned…
        }
    }
}

    Input System

    Input.GetKeyDown belongs to the old Input Manager: with only the Input System package active (Project Settings → Player → Active Input Handling: Input System Package (New)), it throws an exception. Read the key through the Input System instead:

    using UnityEngine.InputSystem;

if (Keyboard.current != null && Keyboard.current.qKey.wasPressedThisFrame)
    caster.Cast(fireball, out SkillExecution execution);

    The examples of this page use Input; the same replacement applies to them (wasReleasedThisFrame for GetKeyUp).

    Cast checks everything before casting: locked actions (stun), cooldown, cost. The result gives the reason for a refusal. To gray out a button without casting anything, use CanCast(graph).

    By slots¶

    With a SkillSlots component on the caster, you cast by slot number. It is the recommended way: it handles combos, passives and replaced slots.

    Method Use
    CastSlot(slot) Casts the slot's skill.
    PressSlot(slot) / ReleaseSlot(slot) Press and release of a key: required for charged skills (the skill fires on release) and held skills (channeling).
    CanCastSlot(slot) Checks without casting.
    CancelSlot(slot) Cancels the execution started by the last press.
    GetCooldownRemaining(graph) Time left before it can be cast again (seconds, or turns in turn-based mode). 
    for (int slot = 0; slot < 4; slot++)
{
    if (Input.GetKeyDown(KeyCode.Alpha1 + slot)) caster.PressSlot(slot);
    if (Input.GetKeyUp(KeyCode.Alpha1 + slot))   caster.ReleaseSlot(slot);
}

    Aim¶

    Skills that travel toward a point or a target read the caster's aim, which your controller fills every frame:

    PointedTarget aim = caster.PointedTarget;
aim.Position = hit.point;                       // aim point (Vector3.positiveInfinity: nothing)
aim.Enemy = hit.collider.GetComponent<SkillTarget>();

    PointedTarget also has Ally (pointed ally), Spell (pointed module body of another skill) and Selection (turn-based mode, below).

    The aim is frozen at cast time (at the end of the cast time for a skill that has one): a projectile that left toward the aim point is no longer influenced by the mouse. An AI or a server can give the aim without going through PointedTarget:

    var options = new SkillCastOptions
{
    Aim = SkillAim.Toward(point, caster.transform.position, CollisionPlane.XZ, caster.transform.forward, target)
};
graph.TryCompute(caster, out SkillExecution execution, options);

    A skill that contains an Aim node (formerly Targeting) follows the mouse until confirmation, then freezes this point for the rest of the skill; it waits for a confirmation: call caster.ConfirmTargeting() on click, caster.CancelTargeting() on right-click (the cost is refunded). caster.IsAiming tells that an aim is in progress.

    Lock your controller¶

    The tool moves an entity during a knockback, a rush or an attack's lunge, and locks its movement during a stun, but it does not drive your controller. Your controller reads the entity's locks and skips its own movement while it is locked:

    using UnityEngine;
using UnleashSkill;

[RequireComponent(typeof(CharacterController))]
public class PlayerMovement : MonoBehaviour
{
    [SerializeField] private SkillCaster caster;
    [SerializeField] private float speed = 6f;
    private CharacterController controller;

    void Awake() => controller = GetComponent<CharacterController>();

    void Update()
    {
        Move(new Vector3(Input.GetAxisRaw("Horizontal"), 0f, Input.GetAxisRaw("Vertical")), Time.deltaTime);
    }

    public void Move(Vector3 input, float deltaTime)
    {
        // Knockback, rush, stun, root, attack lunge: the skill moves the entity (or nothing does), not the input
        if (caster.IsMovementLocked)
            return;

        controller.Move(Vector3.ClampMagnitude(input, 1f) * speed * deltaTime);
    }
}
    Property True while
    IsMovementLocked a skill moves the entity (Lock Controller During Forced Movement option, until the tick after the last movement), a status locks it (Stunned, Rooted of a new configuration), a dodge or an attack phase that locks movement is running.
    IsActionLocked the entity can no longer cast (Stunned, an attack phase that locks actions): Cast and CanCast already refuse (ActionLocked). Read it to gray out the skill bar.

    The OnLockChanged event is raised when a lock starts or ends (an animation of the stunned character, for instance). Your code can lock the entity itself: caster.Lock(source, EntityLockFlags.Movement), then caster.Unlock(source).

    Interrupt¶

    • caster.CancelSkill() interrupts all the caster's running skills, caster.CancelSkill(graph) those of one skill.
    • When the caster dies or is disabled, its running skills are canceled, except those set to outlive it (see Skill settings).

    Turn-based¶

    In turn-based mode (configuration, General settings), durations are counted in turns: call AdvanceTurn() once per turn of each entity, for example at the end of its turn. It is the only moment its timed effects advance:

    • Caster (caster.AdvanceTurn()): its running skills (cast, area, channeled beam, Delay, Repeat, Timer), its statuses, then its cooldowns.
    • Other entity (target.AdvanceTurn(), a SkillTarget): its statuses. The burn applied by a Fireball advances on the turn of the target that burns, not on the caster's.

    A duration field keeps a single value: the same one is read in seconds in real time and in turns in turn-based mode, without conversion when the mode changes. The editor shows the unit according to the mode (“Duration (turns)”). A duration is rounded up to the next turn (0.5 → 1 turn), a rate is a whole number of turns (1 = every turn). Continuous fields (growth of an area, speed and range of the Movement) are marked visual only: they have no effect on the game.

    A skill resolves instantly, in the call that casts it: no projectile flight or detection in space. Its targets are those the player selected before casting:

    caster.PointedTarget.Selection.Clear();
caster.PointedTarget.Selection.Add(target);  // one or more entities
caster.CastSlot(0);                          // damage, statuses… applied before returning

    Without a list, the aimed enemy (PointedTarget.Enemy), then the aimed ally (PointedTarget.Ally), act as the selection.

    Module In turn-based mode
    Projectile, Spell body Hits the selected entities directly. Its On hit keeps its filter (enemy, ally) and its number of targets: a Fireball with 1 target hits the first selected one.
    Area One activation at cast on the selected entities (wherever they are). With a duration, one activation on each turn of its rate, on the same entities (those of the cast), then the area ends at the end of its duration in turns.
    Beam Instant: one shot. Delayed: one shot after its delay in turns. Channeled: one shot at cast then one on each turn of its rate during its duration in turns. Always on the entities selected at cast.
    Attack Resolves in the turn it is cast: its phases follow one another at once (Attack phase hears each of them), the impact hits each selected entity once, wherever it is, then the attack ends. Its phase durations only time the replay; the caster does not move.
    Summon Its lifetime is counted in the caster's turns: a 3-turn summon disappears during the caster's third AdvanceTurn(). Its movement and its contact (On hit) stay on the world tick.
    Chain Bounces only between selected entities, within bounce range.
    Aim Does not aim: it freezes the current selection for the following modules.
    Delay, Repeat, Timer Their delay, interval and duration are counted in the caster's turns.
    Cast time Counted in the caster's turns (Skill settings, “Cast time (turns)”): a 2-turn cast fires the skill during the caster's second AdvanceTurn(), on the selection of that moment; 0: the skill resolves in the call. The During cast output runs in the meantime (its Delays advance on the same turns), an interruption cancels the skill and refunds its cost. A charged cast without a key fires at its minimum in turns. CastInTurns is true and CastRemaining is in turns, for a cast bar.
    Statuses Duration and period (Periodic behavior) in the holder's turns: a 2-turn burn with period 1 ticks on each of the target's two turns, then expires.

    The skill stays active as long as an area, a channeled beam or a delay is not over: it ends during the AdvanceTurn() that reaches the end of its duration. The world does not need to run between two turns; if it runs (for the visuals), it does not advance these durations.

    A wall (Blocker) stays still in turn-based mode; its lifetime is counted in turns.

    Visual replay. The fight is resolved in the call, but its presentation is replayed over time: a projectile's visual flies from its spawn point to its target at the speed of its Movement, and the impact (effect, sound, and everything its On hit nodes fire: displayed damage, statuses) is presented on arrival. With several targets (piercing), each one is presented at its arrival time and the visual flies to the farthest. A projectile without movement presents everything at cast. An impact set to play on stop is played on the contact that ends the projectile (its On hit reaches its number of targets), otherwise on the farthest target. The total duration is known as soon as the cast returns: the last replayed impact, plus the own duration of the effects it starts (one-shot effect, sound, shake, animation, read from the presentation library):

    SkillExecution execution = …;                  // execution cast (already finished on the game side)
float wait = execution.PresentationDuration;   // seconds until the last effect has played

    Without presentation (Presentation Enabled unchecked, see Simulation), no module visual is created and the duration is 0.

    Areas and beams. Their visual is shown at cast and stays in place while they last (an area that follows its caster or its target moves with it on each turn). After its last activation, it stays visible for the Turn Display Duration of its Module Visual (1 second by default), then its end is presented (expiration effect and sound, visual removed). An instant area or beam, resolved in the cast call, is thus visible for that duration, which counts in PresentationDuration.

    Waiting before the next turn. Your turn manager does not need to compute this wait: the execution tells when the next turn can start, according to the Turn wait setting (configuration, General settings; a skill can override it in its Skill settings):

    Turn wait IsTurnReady becomes true
    Presentation (default) Once the logic of the cast is resolved, and its presentation has played (PresentationRemaining at 0).
    Execution Once the logic of the cast is resolved, without waiting for the effects.
    None Right away.

    The logic is resolved (IsTurnLogicResolved) when the execution is finished, or when it only waits for turns: a cast, an area, a channeled beam, a Delay counted in turns does not hold the turn, while an aim, a dash or a module still counted in seconds (Attack) does.

    caster.CastSlot(0);
SkillExecution execution = …;
execution.TurnReady += e => turnManager.NextTurn();   // raised once, after the frame that makes the turn ready

    TurnReady is raised by the manager's presentation frame (also when the presentation is disabled), the first frame after the cast for a skill that is ready at once. After AdvanceTurn(), what the turn starts (outputs of an expired Delay) is waited for in the same way and TurnReady is raised again. You can also poll IsTurnReady.

    Make an entity die¶

    A stat set to “trigger death at zero” (HP) makes the entity die. The game can also kill it itself with TriggerEntityDeath(). By default, a dead SkillCaster cancels its skills and disables itself; override OnEntityDeath() to change this behavior (death animation, ragdoll…).
