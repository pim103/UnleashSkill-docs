    Graph, nodes and ports¶

    A skill is a SkillGraphModel asset: a list of nodes and connections, plus the skill settings (cooldown, cost, cast time…).

    The Start node¶

    Every skill has a Start node, called when it is cast. Its outputs:

    • Module: toward the first module (projectile, area, attack…);
    • Trigger: toward immediate actions (heal the caster, status on self…);
    • During cast (skill with a cast time): a branch that starts at the beginning of the cast and stops at its end (charge visual, caster slowdown).

    Node families¶

    Family Role Examples
    Module An object of the skill that exists in the world, with a body that moves and hits Spell body (projectile), Area, Beam, Attack (melee), Summon
    Behavior Modifies a module: how it moves, how it grows Movement, Scale over time
    Condition Listens to a module or filters the targets On hit, On expire, On tick, Entity type, Chance, Stat condition
    Support Shapes the flow: wait, repeat, split, choose targets Delay, Repeat, Fork, Chain, Target selection, Aim, Check condition, Random choice
    Action Does something to the targets or to the game Damage, Heal, Apply status, Reactions, Dash, Kill, Cast skill, Replace slot
    Trigger Listens to the game while the skill lasts On event, Timer, Stat listener
    Presentation Effects, sounds, animations, shakes — no effect on the fight Play effect, Play sound, Play animation, Camera shake

    The complete list, with each node's fields, is in the node reference.

    Ports¶

    Each connection links an output to an input of the same type. The port color tells its type:

    Type Color What goes through Example
    Module Blue The main flow between modules Start → Spell body
    Trigger Green The firing of an action, with its targets On hit → Damage
    Condition Orange Listening to a module, or a filter Spell body → On hit
    Support Purple A behavior modifier Movement → Spell body
    Selection Cyan A setting, not flow: how a node chooses its targets Target selection → Area (see Aim, anchors and directions)

    A few nodes have several outputs of the same type, named:

    • Check condition: True / False;
    • Target selection: Targets / No target, and Selection (setting of another node);
    • Random choice: Output 1, Output 2…;
    • Area, Attack, Beam: Targets in the area or Hit targets (actions on the targets) / Listeners (nodes that listen to the module, such as On tick);
    • Summon: Summon / Listeners;
    • Start: cast / During cast.

    Reading a graph¶

    A graph reads from the Start, following the arrows. An output can go to several nodes: they all run, each one with its own copy of the targets (see Targets and branches).

    [Start] ─► [Spell body] ─► [On hit] ─┬─► [Damage]
                ▲                    └─► [Apply status]
            [Movement]

    In the editor¶

    • Space or right-click → Create Node: add a node (search by name).
    • Drag from one port to another: connect; only compatible ports snap together.
    • The main fields are shown on the node; the secondary settings are folded in Options. Some fields only appear when another one makes them useful (the maximum range only appears in the Movement's “range” mode).
    • Hovering a link or a port shows what flows through it; Labels shows it on every link, and a “!” badge flags a node that reads what it will never receive (see Targets and branches).
    • Save saves the asset. Skill settings shows the skill's settings in the inspector. Preview opens the skill playback.
