    Simulation world¶

    User version: Simulation world.

    Code: Assets/UnleashSkill/Runtime/Simulation/ (assembly UnleashSkill). The Simulation/Collision/ core is pure C#, in Burst format (blittable structs, arrays, no managed reference in the data). To keep a pure .NET server possible, new code in Simulation/ does not import UnityEngine when it can avoid it.

    Golden rule¶

    The simulation never reads the scene, except the static scenery (through its backend) and the pose of the entities at the start of the tick. Everything else is data: no Physics.* query in a node, no SkillPrefab transform read for logic.

    The tick¶

    SkillWorld is owned by UnleashSkillManager.World, created on first request with a copy of the SimulationSettings of the active configuration (World.Settings changed from code never touches the asset: Where to change a setting). UnleashSkillManager.Update calls World.Update(Time.deltaTime): an accumulator (FixedStepClock) plays zero, one or several ticks (TickRate, 60 by default), capped by MaxTicksPerFrame (the extra ticks are dropped: the game slows down, DroppedTicks). World.Step() plays exactly one tick (tests).

    Order of a tick (SkillWorld.Step, numbered comments in the code):

    1.  Snapshot N: pose of the entities (hurtboxes), time scale of each body, hitstop
2a. Simulation steps of the bodies (IBodyStepListener: modules' OnBodyStep, behaviors); queries queued
2b. Sweeps N → N+1 of the simulated bodies
3-4 Grid rebuilt (queried layers only), batch run: sweeps then queries, against bodies and scenery
5a. Resolution of the simulated bodies (HitPolicy), in identifier order
5b. Resolution of the one-off queries, in queuing order
6.  Query continuations (ModuleQuery), then impacts distributed (OnHit…)
6b. Step listeners (IWorldStepListener): executions (OnSimulationStep), statuses, locks, combos, cooldowns, regeneration
7.  Movements: one request per entity (the highest priority), applied by its IMovementDriver → pose N+1
8.  Snapshot pushed into BodyHistory
(frame) The visual interpolates between the last two states (InterpolationAlpha)

    Contracts to respect:

    • During a tick, entities are still for collision (pose read at step 1).
    • Movements requested during tick N (RequestMovement: dash, knockback, pull) are resolved at step 7: a single request applies per entity, by priority, without accumulation; Block (root, stun) wins except against Forced. The pose actually reached by the Rigidbody or the CharacterController is authoritative.
    • A node started during a tick waits for the next tick for its first OnSimulationStep.
    • Results sorted by time of impact (or distance), then by identifier: it is a gameplay specification, covered by tests.

    Bodies and entities¶

    Element Code Notes
    Shape Shape (Sphere, Capsule, Box; queries: Ray, Cone, Ring) Local offset possible
    Body Body in BodyStore (SoA, stable identifiers BodyId) Identity: OwnerEntityId, SourceExecutionId, Team (hashed UUID)
    Simulated body AddSimulatedBody(SimulatedBodyDesc) Velocity, HitPolicy, filter, listener; Intangible (carrier), Blocker (wall)
    Entity ISimulationEntity, implemented by SkillTarget; SkillEntityRegistry Registered on enable; its Hurtboxes become bodies (default capsule derived from the bounds)
    Movement IMovementDriver (CharacterController, otherwise Rigidbody, otherwise transform) Replaceable through SkillTarget.MovementDriver
    Static scenery IStaticScenery: PhysicsScenery3D, PhysicsScenery2D, none Unity layers of SceneryLayers; a single batch per tick. A body's sweep carries the plane's normal (SceneryQuery.PlaneNormal): a 3D backend stops a body moving along the plane only where the scenery crosses its height
    Dynamic obstacle Body of the Obstacle layer Wall (Blocker support), shield

    On the module side, ModuleBody wraps the body: Spawn, Position, MoveTo, SetDirection, SetShape, Subscribe(IModuleHitListener), Remove. A module's shape is its Scale box, approximated by a capsule (BoxApproximation). Position, Velocity and Rotation are Unity.Mathematics types; a game that does not reference that package reads WorldPosition, WorldVelocity and Direction (Vector3, see Skills → Testing a skill). In the same way, a static body (a test wall, AddBody) is placed with Shape.Box(x, y, z), Body.WorldPosition and Body.WorldRotation (float, Vector3, Quaternion; see Walls and variants of a skill).

    Hit rules: HitPolicy¶

    Serialized in the nodes (OnHit, modules):

    Field Effect
    maxTargets Piercing: 1 = classic projectile, 0 = unlimited (always capped by DefaultMaxCandidates)
    rehit (Once, EveryTick, Cooldown) + rehitCooldown Re-hit of the same target (delay in body time)
    blockedByObstacles (Inherit, Yes, No) Override of the layer matrix for obstacles
    requireLineOfSight Nothing is hit behind an obstacle

    Detection and resolution are separate: the core finds the candidates and their times of impact, the HitPolicy decides (piercing, re-hit, blocking). A target refused by a listener's filter (AcceptsHit) is gone through without counting.

    Layers¶

    SimulationLayers: Entity (0), Skill (1), Obstacle (2), TimeZone (3), then up to 28 custom layers. LayerMatrix (configuration, Simulation menu) gives for each pair Ignore, Touch (event) or Block (stops a sweep). Query filters (SimulationFilter.ForSkill(caster, execution, team)) leave out the caster, the same execution, or allies (friendly fire).

    One-off queries¶

    For a detection outside a body (instant area, beam, Chain bounce):

    // In the runtimeData: one continuation per instance
var query = new ModuleQuery(caster: caster, context: context, onResult: (world, hits) =>
{
    // Called during the tick that runs the query (step 6); hits is only valid here
    var targets = new List<SkillTarget>();
    ModuleTargeting.CollectTargets(hits, caster, filter, targets);
    // ... fill a branch, fire the outputs, or copy what must be kept
});
query.Overlap(world, shape, position, rotation, ModuleTargeting.QueryFilter(caster, context, ignoreCaster: false));
    • Create the ModuleQuery with the caster and the branch (new ModuleQuery(handler, caster, context)) so that it also works in turn-based mode: it then does not go to the world, but returns one contact per selected entity (TurnBasedSelection; a policy requiring line of sight, HitPolicy.RequireLineOfSight, keeps only those seen from the query's origin, tested against the scenery and the obstacles as in real-time mode), with a continuation deferred to the end of the start (SkillExecution.Defer). With followsSelection: false (new ModuleQuery(handler, caster, context, followsSelection: false)), it always goes through the world, even in turn-based mode (contact of a summoned entity, hitbox of an attack, Target selection). Created with the caster and the branch, an exception thrown by its continuation cancels the execution; the constructor without a caster (outside any execution) leaves it to the world (SkillWorld.ExceptionHandler).
    • ModuleQuery.Overlap, Sweep, Raycast queue into the batch; Pending counts the pending results (a module ends when everything has come back).
    • Queued during step 2 (OnBodyStep), the query runs in this tick; queued elsewhere (an OnStart outside a tick), it runs at the next tick. A continuation cannot queue again for the same tick.
    • The QueryHandle and its results are only valid during the continuation: buffers recycled at the next tick.
    • ModuleTargeting.CollectTargets converts the impacts into SkillTargets of the registry: targetable, alive, team filter, cut at the first block.

    Time¶

    Notion API
    World step world.DeltaTime = tick duration × global scale (0 during a global hitstop)
    Global scale GlobalTimeScale; TickGlobalScale = scale of the current tick
    Global hitstop ApplyHitstop(ticks): freezes everything, movements included (kept for the first unfrozen tick)
    An entity's own time ApplyHitstop(entity, ticks), SetEntityTimeScale(entity, scale), ResetEntityTime
    A body's hitstop ApplyHitstop(bodyId, ticks)
    Time zones AddTimeZone(shape, position, rotation, scale); overlapping scales multiply; sampled at the start of the tick
    Effect clock SimulationClock: DeltaTime, DeltaTimeFor(entity), Reached(elapsed, duration), Fixed(dt) for tests

    DeltaTimeFor(entity) = tick step × own time × the entity's time zones; for an entity carried by a body (skill instance), it is that body's step. A simulated body advances at its own step (GetBodyDeltaTime), received by OnBodyStep.

    Performance and Burst¶

    Performance choices:

    • Grid of the targetable bodies (GridInsertion.QueriedLayers): only the layers that a query of the batch accepts are inserted, rebuilt on each tick.
    • Burst on the hot path (CollisionKernel: grid, broad phase, shape tests, filter, sort), as a direct synchronous call, strict floating-point mode. A single code: managed if SimulationSettings.UseBurst is false or if the editor's Burst compilation is off. No parallel jobs.
    • Still managed: sweep preparation, HitPolicy resolution, distribution, time zones.
    • SimulationProfile records the time of each step of a tick, for profiling in a build (Diagnose and measure).

    Debugging¶

    • SimulationSettings.Debug: warnings (dropped ticks, truncated candidates) and SimulationTrace (circular buffer: tick, query, candidates, impact kept, rule applied).
    • SimulationSettings.Gizmos: bodies, last queries, sweeps and impacts in the Scene view (SkillWorldGizmos).

    To turn them on during a game, change UnleashSkillManager.World.Settings: a copy, the configuration stays as it is. Counters, profile and what ResetWorld() keeps: Diagnose and measure.

    Network extension points¶

    ISkillAuthority (LocalAuthority by default) decides on impacts; BodyHistory keeps N snapshots for lag compensation. Nothing is connected in the base asset: they are the entry points of a network layer (dependent asset).
