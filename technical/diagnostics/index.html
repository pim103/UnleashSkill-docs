    Diagnose and measure¶

    What a game can read at runtime to display counters, measure the simulation or find out why a skill missed. Everything here is read-only and costs nothing while it is not used.

    Counters¶

    What Read Note
    Active executions UnleashSkillManager.ActiveSkillExecutions Skills cast, passives, skills cast by a skill. A completed execution is removed by UnleashSkillManager.Update (see Without the manager)
    Living skill instances SpellInstanceRegistry.Instances (UnleashSkill.Nodes.Modules) One per module body still alive; Model tells which module (an Area, a Spell body…), Caster who cast it
    Registered entities SkillEntityRegistry.Targets (UnleashSkill.Simulation) Casters and targets known to the engine
    Dropped ticks UnleashSkillManager.World.DroppedTicks Ticks dropped since the world was created, because a frame needed more than MaxTicksPerFrame (the game slows down)
    Current tick UnleashSkillManager.World.Tick Ticks played by the world
    Module visuals (real-time mode) SkillPooler.Current (UnleashSkill.SkillUtils): ActiveVisualCount, TotalPooledVisualCount, PooledVisualCount(prefab), CreatedVisualCount Visuals displayed, waiting in the pools (all prefabs, or one), instantiated since the pooler started. In real-time mode, every module visual is carried by a SkillPrefab of the pooler. A summoned entity is not counted. Null without a manager
    Module visuals (turn-based mode) (UnleashSkillManager.Presentation.ModuleVisuals as ModuleVisualPlayer): ActiveCount, PooledCount(prefab) Only the visuals played by the presentation: replay of a module resolved on the selection, area or beam in turns. Stays at 0 in real-time mode 
    int executions = UnleashSkillManager.ActiveSkillExecutions.Count;
int areas = 0;
foreach (SpellInstance instance in SpellInstanceRegistry.Instances)
    if (instance.Model is AreaModel)
        areas++;

SkillPooler pooler = SkillPooler.Current;
int visuals = pooler != null ? pooler.ActiveVisualCount : 0;

    Profile of the simulation¶

    UnleashSkillManager.World.Profile (SimulationProfile) records the time of each step of a tick. Disabled by default: no measurement, zero cost.

    Member Meaning
    Enabled Measures the following ticks
    Samples Ticks measured since the last Reset()
    AverageTickMs Average time of a tick (all steps), in milliseconds
    WorstTickMs Worst measured tick, in milliseconds
    AverageMs(stage) Average time of one step per tick (SimulationProfileStage: Snapshot, Step, Advance, Grid, Collision, Sort, Scenery, Resolve, Dispatch, Movement, History)
    Hits Impacts distributed to the bodies
    Queries Queries executed (sweeps and one-shot queries)
    GridBodies Bodies inserted into the grid, accumulated over the measured ticks
    Reset() Starts the measurements over 
    SimulationProfile profile = UnleashSkillManager.World.Profile;
profile.Enabled = true;
// … a few seconds later
Debug.Log($"{profile.AverageTickMs:0.000} ms per tick, worst {profile.WorstTickMs:0.000} ms over {profile.Samples} ticks");
profile.Reset();

    The time is measured with System.Diagnostics.Stopwatch: it works in a build, without the Unity Profiler.

    Cost of a refused cast¶

    A game can try to cast every frame while a key is held (SkillCaster.Cast, SkillGraphModel.TryCompute), or check with CanCast / CheckCast. A refused cast (actions locked, skill blocked, attack in progress, cooldown, cost) reads only the caster's own state: its locks, its statuses, its running attacks and dodges (indexed by caster), its cooldowns and its stats. Its cost does not grow with the active executions of the other casters; nothing is created nor paid.

    Trace and warnings¶

    With SimulationSettings.Debug on, the world:

    • writes a trace in World.Trace (SimulationTrace, circular buffer of TraceCapacity entries): Count, trace[i] (TraceEntry: Tick, Kind — sweep, query, impact, rejected, truncated, dropped ticks —, Rule that discarded a candidate, Source, QuerySerial, Target, Count), Clear();
    • sends warnings (dropped ticks, truncated results) to World.WarningHandler, or to Debug.LogWarning if it is null;
    • draws the gizmos chosen in SimulationSettings.Gizmos in the Scene view (bodies, last queries, sweeps, impacts).

    Where to change a setting¶

    The world created by UnleashSkillManager.World works on a copy of the configuration's settings (SimulationSettings.Clone()):

    • For the current game: UnleashSkillManager.World.Settings.Debug = true (or Gizmos, or any other setting read at runtime). The configuration asset is never modified, even in the editor.
    • For good: in the configuration (Simulation settings, or UnleashSkillConfiguration.Simulation from code), then UnleashSkillManager.ResetWorld() to apply it to a running game. Settings read when the world is created (tick rate, cell size, plane, scenery, history depth, trace capacity) only change this way.

    What lives with the world¶

    The profile, the trace, DroppedTicks, the tick count and the bus of events belong to the world. UnleashSkillManager.ResetWorld() (new game) replaces the world:

    • the profile of the new world is enabled if the replaced one's was; its measurements start over;
    • Debug and Gizmos changed from code on the replaced world are kept; the other settings come back from the configuration (a value changed in the configuration before the call wins);
    • the trace, DroppedTicks and the tick count start empty.

    ResetWorld(world) uses the given world and its settings as they are; only its profile is enabled if the replaced world's was. To follow the world from a diagnostics panel, subscribe to UnleashSkillManager.WorldChanged (Extension points).

    Without the manager¶

    In a SimulationSandbox or an Edit Mode test, UnleashSkillManager.Update does not run: a completed execution stays in ActiveSkillExecutions (and in SimulationSandbox.Executions). Count only the executions still running (!execution.IsCompleted), or remove the completed ones with UnleashSkillManager.UnregisterActiveSkillExecution(execution). SimulationSandbox.Dispose() removes them all (Static state and preview).
