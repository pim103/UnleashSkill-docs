    Writing a node¶

    Model and editor node¶

    File Folder Assembly Role
    [Name]Model.cs Runtime/Nodes/[Category]/ UnleashSkill Serialized data and runtime logic
    [Name]EditorNode.cs Editor/Graph/Nodes/[Category]/ UnleashSkill.Editor UI in the graph

    The editor node is optional: EditorNodeFactory looks for the class deriving from DefaultEditorNode<TModel> for the model's exact type, otherwise it creates a DefaultEditorNode<NodeModel>, which shows the [ExposedProperty] fields. The project's convention is still to write one (even empty, like KillEditorNode); it becomes useful for a custom drawing (CustomDraw), named ports or conditional fields.

    The model contains no editor code ([SerializeField] yes; PropertyField, EditorGUILayout no), instantiates nothing (new MonoBehaviour, Instantiate), makes no Physics.* query, never reads Time.deltaTime.

    Attributes¶

    • [NodeInfo("Displayed title", "Category/Displayed title", NodeType.Action)]: title, path in the creation menu, type (Module, Trigger, Conditional, Support, Action). An [Obsolete] class is hidden from the menu but can still be opened. Title and menu are written in English; the editor translates them (each menu segment separately) with the tables of Editor/Localization/.
    • [ExposedProperty] + [SerializeField] + [Tooltip] on each tunable field. The tooltip is written in English, translated at display time, and reused in the node reference of each language.
    • Display attributes (Runtime/Attributes/): [FoldedOption] (folded option), [HideIf] / [ShowIf] (conditional field: hidden or only shown when a field or a property of the model has one of the values, [ShowIf(nameof(shape), AreaShape.Rectangle, AreaShape.Line)]; several conditions combine, the field is hidden if one of them hides it; common resolution FieldVisibility, read by the node editor, the inspector and the generated reference), UUIDs chosen from a list (UuidAttributes.cs, [PresentationDefinitionUuid]), [SimulationLayerName], [UnityLayer], [AnimationBone].
    • A tunable numeric field is a ValueSource (fixed, stat, execution value, distance, stacks, event value, formula), evaluated with Evaluate(caster, context, target).

    Ports¶

    InitPortType() fills InputPortTypes and OutputPortTypes (one entry per port, in order):

    PortType Color Use
    Module Blue Flow between modules (Projectile → OnHit)
    Trigger Green Firing actions (OnHit → Damage)
    Condition Orange Filter (Entity type, Chance)
    Support Purple Modifier (Delay, Fork, Repeat, a module's behaviors)
    Selection Cyan Configuration, not flow: “Selection” output of the Target selection node, “Selection” input of a node that chooses targets (Chain, Fork, Area, Summon)

    A node that chooses targets takes a Selection port, not its own filters. It adds InputPortTypes.Add(PortType.Selection) at the end of its inputs and reads the connected Selection with TargetSelection.ConnectedTo(this, context) (null: its own behavior). It applies the criteria to its own candidates with selection.Criteria.Select(candidates, caster, context, center), or asks for the source's with selection.CollectCandidates(…) (immediate, or a world query whose result arrives at the next tick). The engine never executes a node whose Selection output is connected (SkillGraphModel.IsConfigurationNode), and a Selection connection is not a flow output.

    A node declares what it reads and transforms. The editor shows on each connection what it carries and flags a node that reads what it will never receive; it deduces it from two declarations of the node, read by GraphFlowAnalysis without executing anything:

    • DescribeFlow(FlowState input, int outputPosition, GraphFlowAnalysis analysis): what the output at outputPosition emits when the node receives input. By default a pass-through; null for a configuration output. FlowState is immutable: WithTargets(FlowTargets.ModuleHits, this), WithoutTargets(), WithAim(FlowAim.Targeting, this), WithBranchDirection(this), WithParentBody(this). To override by a node that replaces the targets of its branches (listener, trigger, Selection, Fork), writes the aim point, a branch direction or a body.
    • ReadsTargets, ReadsAimPoint, ReadsParentBody: what the node reads. By default, deduced from its exposed and shown SkillAnchor / SkillDirection fields (anchor “received target” or “each received target”, “aim point”, “module body”). A node that acts on the received targets (damage, status on the target) overrides ReadsTargets, depending on its setting if it can target the caster: public override bool ReadsTargets => base.ReadsTargets || holder == StatusHolderTarget.ReceivedTargets;.

    Warnings (GraphFlowCodes, reused by the validator): W112 acts on the received targets without receiving any (Damage behind the Start), W113 reads the module body without a module upstream (listener, anchor), W114 Selection connected both as configuration and in the flow, W115 loop of nodes that all start their outputs during their start (the engine stops it, see Cast cycle): a node that only starts them later (listener, delay greater than 0) overrides StartsOutputsDuringStart, depending on its setting if needed (public override bool StartsOutputsDuringStart => fireImmediately;); W116 On hit with Max Targets 1 under a carrier module that lasts (Area or channeled Beam with a Duration, Summon): its first target ends the module. Displayed vocabulary: received targets, event target, aim point, branch direction, module body.

    Several outputs of the same type are told apart by their rank: ExecuteChainedNodes(this, caster, context, PortType.Trigger, 1) fires the second Trigger output. GetOutputPortLabel(position) names an output (“True”, “False”, in English: the editor translates it). A switch (Chance, Check condition) ends with CompleteNodeInstanceWithoutOutputs, then fires the single output chosen.

    The four node shapes¶

    Shape OnStart End Examples
    Instant Acts, then CompleteNodeInstance(this, caster), returns null Immediate Damage, Apply status, Play sound
    Failure / false condition CompleteNodeInstanceWithoutOutputs(this, caster), returns null Immediate, without outputs Unmet stat condition, no target
    Persistent Returns a runtimeData object CompleteNodeInstance(this, caster, runtimeData) from OnSimulationStep Delay, Repeat, Timer
    Listener Returns a runtimeData, subscribes ExecuteChainedNodes on each event; ends without outputs at the end of its duration On event, OnHit, On tick

    Never return null without completing the instance: the chain would be blocked (reported in the editor and in a Development Build).

    An exception thrown by a node cancels its execution only (see Cast cycle): do not catch it to hide it. A configuration error that would repeat on each cast (unknown stat, no configuration) goes through LogConfigurationErrorOnce(message), logged once per node.

    Life cycle of an instance:

    Method Called Use
    OnStart(caster, context) At start, instance already registered Logic, returns the runtimeData
    OnSimulationStep(caster, context, runtimeData, clock) On each world tick (step 6b), not on the start tick Count time, deadlines
    OnTurnAdvanced(caster, context, runtimeData) Turn-based: on each AdvanceTurn of the caster, not on the start turn Count time in turns
    OnRuntime(caster, context, runtimeData) Each frame Visual only
    OnEnd(caster, context, runtimeData) Normal end (if the node calls it), cancellation, cleanup Unsubscribe, stop the presentation, mark finished

    OnEnd can be called by Cancel or Cleanup without the node having finished: the runtimeData must be able to be marked finished (an IsFinished flag, as in the example below).

    Time¶

    A persistent node outside a module advances in OnSimulationStep with clock.DeltaTimeFor(entity), the entity that carries the effect:

    • the caster for Delay, Repeat, On tick, Timer, listeners, the cast time;
    • the target for a DoT, a buff, a tag, an immunity (in practice, these are statuses, which advance on their own in the StatusStepper).

    This step includes the global scale, the global hitstop, the entity's own time (hitstop and scale per entity) and the time zones it is in. Deadlines are compared with SimulationClock.Reached(elapsed, duration) (rounding tolerance: 1/60 added 60 times gives 0.99999…).

    Turn-based: a duration field keeps its value, read in turns. At start, if TurnTime.IsActive, convert it (TurnTime.Duration: rounded up to the next turn; TurnTime.Period: whole rate ≥ 1), remember it in the runtimeData (InTurns), and advance by one turn (1f) in OnTurnAdvanced instead of OnSimulationStep, which then does nothing. Mark the field [TurnAware] (TurnUnit.Duration, Period or VisualOnly): the editor shows its unit according to the mode. A module overrides OnBodyTurn (its lifetime in turns is counted by GameObjectModel); its OnBodyStep no longer runs, unless it overrides StepsBodyInTurns to keep a tick step that does not count time (movement, presence: SummonModel). Example: DelayModel.

    A node whose instance still advances on the world tick in turn-based mode (a movement, a delay counted in seconds) overrides HoldsTurn(runtimeData): as long as it returns true, the execution's turn is not ready (SkillExecution.IsTurnLogicResolved, IsTurnReady). False by default: an instance that waits for turns, a listener or a lasting effect does not hold the turn.

    Complete example: persistent node¶

    A “Countdown” that waits for a tunable duration (stat or formula possible), at the caster's time, then fires its outputs if its branch still has a living target, and fails otherwise.

    using UnityEngine;
using UnleashSkill.Execution;
using UnleashSkill.Nodes.Attributes;
using UnleashSkill.Simulation;

namespace UnleashSkill.Nodes.Supports
{
    /// <summary>State of an instance: pure, testable in EditMode without a world.</summary>
    public class CountdownRuntimeData
    {
        public float Duration { get; }
        public float Elapsed { get; private set; }
        public bool IsFinished { get; set; }   // normal end, or cancellation (OnEnd)

        public CountdownRuntimeData(float duration) => Duration = duration;

        public bool Advance(float deltaTime)
        {
            Elapsed += Mathf.Max(0f, deltaTime);   // 0 during a hitstop
            return SimulationClock.Reached(Elapsed, Duration);
        }
    }

    [NodeInfo("Countdown", "Support/Countdown", NodeType.Support)]
    [System.Serializable]
    public class CountdownModel : NodeModel
    {
        [ExposedProperty]
        [SerializeField]
        [Tooltip("Duration in seconds, at the caster's time (hitstop and time zones included)")]
        private ValueSource duration = new ValueSource(2f);

        public ValueSource Duration => duration;

        protected override void InitPortType()
        {
            InputPortTypes.Add(PortType.Trigger);
            OutputPortTypes.Add(PortType.Trigger);
        }

        public override object OnStart(SkillCaster caster, SkillExecutionContext context)
        {
            if (context?.Execution == null)
                return null;   // outside an execution (isolated test): nothing to complete

            // Evaluated once, at start, with the branch's first target
            float seconds = Mathf.Max(0f, duration.Evaluate(caster, context, context.GetPrimaryTarget()));
            if (seconds <= 0f)
            {
                Finish(caster, context, null);   // zero duration: behaves like an instant node
                return null;
            }

            return new CountdownRuntimeData(seconds);
        }

        public override void OnSimulationStep(SkillCaster caster, SkillExecutionContext context, object runtimeData, SimulationClock clock)
        {
            if (!(runtimeData is CountdownRuntimeData data) || data.IsFinished)
                return;

            // The caster carries the wait: its step, not the world's
            if (!data.Advance(clock.DeltaTimeFor(caster)))
                return;

            data.IsFinished = true;
            Finish(caster, context, data);
        }

        private void Finish(SkillCaster caster, SkillExecutionContext context, CountdownRuntimeData data)
        {
            // Reads the targets of ITS branch, never another's
            bool hasTarget = context.Targets.Exists(target => target != null && target.isActiveAndEnabled);

            // Several countdowns of the same node can run (Repeat → Countdown):
            // complete by runtimeData when there is one
            if (hasTarget)
            {
                if (data != null) context.Execution.CompleteNodeInstance(this, caster, data);
                else context.Execution.CompleteNodeInstance(this, caster);
            }
            else
            {
                if (data != null) context.Execution.CompleteNodeInstanceWithoutOutputs(this, data);
                else context.Execution.CompleteNodeInstanceWithoutOutputs(this, caster);
            }
        }

        public override void OnEnd(SkillCaster caster, SkillExecutionContext context, object runtimeData)
        {
            // Also called by Cancel / Cleanup: never fire the outputs afterwards
            if (runtimeData is CountdownRuntimeData data)
                data.IsFinished = true;
        }
    }
}

    Key points: CompleteNodeInstance fires the outputs with the instance's context (each chained node receives a copy of the branch); no reference to Time; the state lives in the runtimeData, not in the model's fields (the model is shared by all executions of the skill).

    Matching editor node (Editor/Graph/Nodes/Supports/CountdownEditorNode.cs):

    using UnityEditor;
using UnleashSkill.Editor.Graph;
using UnleashSkill.Nodes.Supports;

namespace UnleashSkill.Editor.Graph.Nodes.Supports
{
    public class CountdownEditorNode : DefaultEditorNode<CountdownModel>
    {
        public CountdownEditorNode(CountdownModel model, SerializedObject skillGraphObject) : base(model, skillGraphObject)
        {
        }
    }
}

    Listeners¶

    An event node:

    • subscribes in OnStart (world bus: UnleashSkillManager.World.Events.Subscribe(eventUuid, handler), or ModuleBody.Subscribe for a module's impacts) and returns its runtimeData;
    • on each event, creates a dedicated branch (context.CreateBranch()), adds the event's target to it, then ExecuteChainedNodes(this, caster, branch);
    • counts its duration in OnSimulationStep at the caster's pace, then unsubscribes and ends with CompleteNodeInstanceWithoutOutputs;
    • also unsubscribes in OnEnd (cancellation).

    Model to follow: OnGameEventModel (anti-loop through AddSourceListener / HasSourceListener, max count, internal cooldown).

    Modules¶

    A module (Projectile, Area, Beam, Summon, Attack…) derives from GameObjectModel:

    • it has a simulated body (ModuleBody, created by Spawn(SimulatedBodyDesc)), swept by the world; a module that detects by itself (Area, Beam) has a carrier body (Intangible) and queues queries;
    • its logic advances in OnBodyStep(caster, context, runtimeData, deltaTime) (step 2 of the tick, step of the body); OnModuleRuntime (each frame) is reserved for the visual;
    • its outputs are listeners (OnHit, OnExpire) fired right at start (LaunchOutputs), after which it ends with CompleteNodeInstanceWithoutOutputs so as not to fire them again;
    • the position lives in the body (ModuleBody.Position, MoveTo), never in the transform of the SkillPrefab (visual only);
    • behaviors connected as Support (Movement, Scale over time) become IBodyBehaviors;
    • a body movement goes through a trajectory definition (TrajectoryDefinition: Line, Curve, Orbit, Pursuit, Return segments, in the aim frame) run by TrajectoryRunner, never a new movement behavior: on each tick, the current segment computes the desired displacement and the runner sets the body's velocity (swept by the world, never MoveTo), at the body's step × the definition's scale, oscillations added, slide and bounce applied. A new segment derives from TrajectorySegment (data, [Serializable]; the blocking rule, its maximum number of blocks and the oscillations are inherited) and returns its flight state (TrajectorySegmentRun.Step); it overrides OnBounce if it holds its own direction, OnFrameTranslated if it targets a fixed world point (forced displacement). A height along the plane's normal goes through TrajectoryRunner.Rise(delta), which adds the movement in 3D and only offsets the visual in 2D (SimulatesHeight); the rules in flight (Hits In Flight, Ignores Obstacles) are inherited and applied by the runner. A reusable definition goes in the TrajectoryLibrary (Trajectory node), read by ConfigurationData.GetTrajectory.

    GameObjectModel hooks: CreateRuntimeData, OnSpawned, LaunchOutputs, OnBodyStep, OnModuleRuntime, and the properties UsesSimulatedBody, HasIntangibleBody, FollowsCasterTime, HasOwnLifetime. Detections: Simulation world.

    Presentation¶

    A node instantiates nothing and holds no ParticleSystem, AudioSource or Animator: it emits a command (see Presentation). Gameplay never depends on the returned handle.

    Texts shown in the editor¶

    The text of a node (title, menu, tooltips, [Header], output labels) is written in English in the model, and translated at display time from the tables of Editor/Localization/ (NodeText, EditorLocalization). Every other text shown by the editor (editor node, drawer, window) goes through Tr("…") or TrFormat("… {0}", value) (using static UnleashSkill.Localization.Localizer;), with its translations in a .po table registered with Localizer (see Extension points). Logs and exceptions stay in English, without Tr.

    New node checklist¶

    1. Model in a runtime assembly that references UnleashSkill, editor node (if the default one is not enough) in an editor assembly that references UnleashSkill.Editor.
    2. Tests of its ports and behavior: a model is instantiated without MonoBehaviour, in EditMode.
    3. A state read during a tick? Keep it per world, never in a static (state of an add-on).
    4. Texts in English, their translations in a .po table registered with Localizer (title, menu segments, tooltips, output labels).
    5. A tunable position or direction: a SkillAnchor / SkillDirection field (sources limited by [AnchorSources] / [DirectionSources]), resolved by Resolve, never a new enum or a read of caster.PointedTarget (read context.Aim). Its default is the field initializer, the same for a node created in the editor, built from code or read from JSON.
    6. What it reads and transforms: DescribeFlow if it changes the targets, the aim point, the branch direction or the body of its outputs, ReadsTargets if it acts on the received targets (see Ports); tooltips use the “received targets” vocabulary, never “branch targets”.
    7. Replacing an old node: the old model's class becomes [Obsolete] (SearchNodeProvider then removes it from the creation menu), never deleted while assets use it.
