    Premier sort : une boule de feu¶

    Objectif : un projectile qui part devant le lanceur, touche le premier ennemi, lui inflige 20 dégâts et le brûle pendant 2 secondes.

    Ce guide part de la scène de Mettre en place une scène et de la configuration par défaut (stat HP, teams Player et Enemy). Il crée en chemin ce que la configuration par défaut n'a pas : un statut de brûlure et un visuel pour le projectile.

    1. Préparer les données¶

    Un statut de brûlure¶

    1. UnleashSkill → Main Menu → Statuts, puis Ajouter un statut.
    2. Nommez-le Burn, ouvrez ses Paramètres : Default Duration 2 (secondes).
    3. Ajouter un comportement ▾ → Périodique : Effect Damage, Stat HP, Interval 0.5, Amount Per Stack 3. La cible perd 3 HP toutes les demi-secondes tant qu'elle brûle.
    4. Cliquez Sauvegarder.

    Un visuel pour le projectile¶

    Un projectile fonctionne sans visuel, mais reste invisible. N'importe quel prefab peut lui servir de visuel :

    1. GameObject → 3D Object → Sphere, puis glissez-la de la Hierarchy vers la fenêtre Project (par exemple dans Assets/) : elle devient le prefab Sphere. Supprimez la sphère de la scène. Son collider est ignoré : un visuel n'a aucun rôle dans la logique.
    2. UnleashSkill → Main Menu → Présentation, onglet Visuels de module : tapez Fireball dans le champ du nom et cliquez Créer.
    3. Dans la nouvelle définition, glissez le prefab Sphere dans Body Prefab. Cliquez Sauvegarder.

    Voir Présentation pour les effets de lancement, de boucle et d'impact qu'un visuel peut aussi jouer.

    2. Créer le sort¶

    • UnleashSkill → NodeEditor, puis Créer un nouveau graphe de sort. Choisissez un nom et un dossier (par exemple Assets/Skills/MaBouleDeFeu.asset).
    • Le graphe s'ouvre avec un node Start : c'est le point d'entrée du sort, appelé au lancement.
    • Autre chemin : clic droit dans la fenêtre Project → Create → UnleashSkill → Skill Graph, puis double-clic sur l'asset.

    Pour ajouter un node : Espace dans le graphe, ou clic droit → Create Node. Une fenêtre de recherche liste les nodes par catégorie (Action, Behavior, Condition, Module, Présentation, Support, Trigger).

    3. Le projectile¶

    1. Ajoutez un Module → Corps de sort. C'est un module : un objet de sort qui existe dans le monde (projectile, zone, rayon…).
    2. Reliez la sortie Module (bleue) du Start à l'entrée Module du Corps de sort.
    3. Dans le Corps de sort, choisissez le visuel Fireball dans Visual.
    4. Ajoutez un Behavior → Mouvement et reliez sa sortie Support (violette) à l'entrée Support du Corps de sort. Réglez :
      • Speed : 10 (mètres par seconde) ;
      • Direction : Avant du lanceur ;
      • End Mode : Lifetime, Duration : 5 (le projectile disparaît après 5 s s'il n'a rien touché).

    La taille du projectile est le champ Scale du Corps de sort : (1, 1, 1) donne une sphère de 0,5 m de rayon.

    4. Toucher un ennemi¶

    1. Ajoutez un Condition → Au contact et reliez la sortie Condition (orange) du Corps de sort à son entrée Condition. Ce node écoute les contacts du projectile.
    2. Laissez Target Filter sur Enemy : seules les entités d'une autre équipe déclenchent la suite. Le lanceur n'est jamais touché par son propre projectile.
    3. Hit Policy : laissez une cible avant arrêt. Le projectile s'arrête au premier ennemi touché (0 = il traverse tout).

    5. Les effets¶

    1. Ajoutez un Action → Dégâts Simple et reliez la sortie Trigger (verte) de Au contact à son entrée Trigger.
      • Damage : 20 ;
      • Target Stat : HP ;
      • Damage Type : laissez vide (la configuration par défaut n'en a pas ; voir Dégâts et réactions).
    2. Ajoutez un Action → Appliquer statut, relié lui aussi à la sortie Trigger de Au contact.
      • Status : Burn ;
      • laissez Override Duration décoché : le statut dure le temps de sa définition (2 s).

    Les deux nodes reçoivent la cible touchée : ils s'appliquent à elle seule.

    [Start] ──Module──► [Corps de sort] ◄──Support── [Mouvement]
                         │ Condition
                         ▼
                    [Au contact]  (Enemy)
                         │ Trigger
                ┌────────┴────────┐
                ▼                 ▼
         [Dégâts Simple]   [Appliquer statut]
              20 HP              Burn

    Cliquez Save dans la barre d'outils.

    6. Voir le sort dans l'aperçu¶

    Cliquez Aperçu dans la barre d'outils : un panneau s'ouvre à côté du graphe, avec un lanceur et des mannequins. Le sort se rejoue en boucle et redémarre à chaque modification du graphe.

    • ⏮ redémarre, ▶ met en pause, ⏭ avance d'un tick, le menu de vitesse ralentit la lecture ;
    • Cadrer recentre la caméra ;
    • Mise en scène règle le nombre, la disposition et l'équipe des mannequins.

    7. Le lancer en jeu¶

    1. Ouvrez la scène de Mettre en place une scène : Player a un SkillTester.
    2. Dans l'éditeur de graphe, cliquez Lier à la scène : le sort est mis dans l'emplacement 0 du SkillTester.
    3. Lancez le mode Play et appuyez sur Espace : la sphère part vers Enemy et le touche. Sélectionnez Enemy pour suivre ses HP dans l'inspecteur.

    Chaque boule de feu retire 20 HP, plus 12 HP de brûlure (4 ticks de 3). À la quatrième, Enemy atteint zéro HP et disparaît.

    Rien ne se passe ?

    Vérifiez que Enemy est devant Player (axe bleu), dans la team Enemy, et que l'UnleashSkillManager a sa configuration. Le Dépannage liste les causes habituelles.

    Pour aller plus loin¶

    • Trois projectiles en éventail : un Support → Fork entre le Start et le Corps de sort.
    • Une explosion à l'impact : remplacez les dégâts par un Module → Zone d'effet déclenché au contact.
    • Un temps de recharge et un coût en mana : Paramètres du sort dans la barre d'outils (voir Paramètres d'un sort).

    La décomposition complète, avec ces variantes, est dans la recette Fireball.
