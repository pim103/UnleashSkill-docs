    Installation¶

    Prérequis¶

    • Unity 6.0 LTS (6000.0) ou plus récent.
    • Paquets Unity requis par l'outil : Burst et Mathematics (noyau de collision) et uGUI (barres de stats des entités). Ils sont déclarés comme dépendances du package : si l'import ne les ajoute pas, installez-les depuis Window → Package Manager → Unity Registry. L'éditeur utilise UI Toolkit, un module intégré.
    • Optionnels : Cinemachine 3 (tremblements de caméra), Addressables (chargement des graphes par leur nom avec SkillGraphLoader : le label SkillGraph au lieu des dossiers Resources, voir Les graphes de sorts dans un build), Input System (touches de SkillTester, sinon l'ancien Input Manager). L'outil les détecte et fonctionne sans eux.
    • Aucun pipeline de rendu imposé : Built-in, URP et HDRP conviennent.

    Importer le package¶

    1. Ouvrez votre projet (un nouveau projet 3D suffit pour ce guide).
    2. Window → Package Manager, puis My Assets : sélectionnez UnleashSkill, cliquez Download, puis Import.
    3. Laissez tous les fichiers cochés et cliquez Import.

    Le package ajoute un seul dossier :

    Dossier Contenu
    Assets/UnleashSkill/Runtime/ Le framework (assembly UnleashSkill) : manager, lanceurs, nodes, monde de simulation, présentation
    Assets/UnleashSkill/Editor/ L'éditeur (assembly UnleashSkill.Editor) : menu principal, éditeur de graphe, aperçu, traductions
    Assets/UnleashSkill/Documentation/ Cette documentation pour un usage hors ligne (PDF), le journal des modifications
    Assets/UnleashSkill/LICENSE.md, Third-Party Notices.txt Licence et mentions des tiers

    Vos propres données ne vont jamais dans ce dossier : une mise à jour du package n'y touche pas.

    Première ouverture¶

    Quand l'éditeur compile le package pour la première fois dans un projet sans configuration, il crée le dossier des données Assets/UnleashSkillData/ avec :

    • UnleashSkillConfiguration.asset, une configuration par défaut : teams Player et Enemy, type d'entité Character, stats HP (100, mort à zéro), Mana (100) et Attack (10), template de stats Default ;
    • Presentation/PresentationLibrary.asset et TrajectoryLibrary.asset, bibliothèques vides d'effets, de sons, de visuels et de trajectoires.

    Le dossier des données se déplace : Edit → Project Settings → UnleashSkill.

    Langue de l'éditeur¶

    L'éditeur est en anglais par défaut. Pour le passer en français : Edit → Preferences → UnleashSkill → Language. Les fenêtres ouvertes se reconstruisent aussitôt, sans recompiler ; les menus Unity (UnleashSkill → …) restent en anglais. Cette documentation existe dans les deux langues (sélecteur de langue en haut de la page).

    Le menu principal¶

    Ouvrez UnleashSkill → Main Menu. C'est le point d'entrée de tout l'outil :

    • en haut, Charger une configuration / Créer une configuration : la configuration active (voir Configuration) ;
    • Éditeur de sort : ouvre l'éditeur de graphe ;
    • Sorts : la liste des sorts de la configuration ;
    • Présentation : effets, sons, tremblements, animations et visuels de module ;
    • section Configuration : Paramètres généraux, Simulation, Stats, Types d'entité, Teams, Types de dégâts, Tags, Templates de stats, Réactions, Statuts, Marques, Événements, Tags de sort.

    L'éditeur de graphe s'ouvre aussi par UnleashSkill → NodeEditor, ou par un double-clic sur un sort dans la fenêtre Project.

    Vérifier l'installation

    La console n'affiche aucune erreur, le menu principal s'ouvre et affiche Default Configuration en haut. Sinon, voir Dépannage.
