    Fields¶

    Field Type Default Description
    Variable Skill variable — Skill variable written (skill settings)
    Operation Choice: Set, Add Set Set the variable to the value, or add the value to it
    Value Dynamic value 0 Value written: fixed, or read at cast time (damage dealt, stat, number of targets…)

    Usage¶

    When to use: to remember a value during the cast and use it further on: the number of enemies hit by the first wave, the damage dealt by the opening strike, the caster's health at cast time. The Variable is declared in the skill's settings (Skill settings → Variables); the node sets it to the Value or adds the value to it (Add: a counter). The value is evaluated for the first received target.

    The variable is shared by the whole execution, every branch included: any later node reads it through a dynamic value (Execution value mode, or Var(name) in a formula).

    When not to use: to signal a value to other skills, use Emit event.

    Example:

    [Area] ──Targets in the area──► [Store value] (Hits, Add 1)
[Delay] (1 s) ─► [Simple damage] (Amount: 10 × Hits)
